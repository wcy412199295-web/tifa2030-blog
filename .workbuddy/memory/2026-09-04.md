## ⚠️ 本次新增部署经验（重要，下次先看）

增量推送流程出现 **non-fast-forward** 拒绝：本地 .deploy_git 的基线与远程 gh-pages 不一致（远程被上次部署推到 597556a，而本地基线仍是 c34fcb5）。

**修正后的可靠流程**（本次验证通过）：
```
git -C .deploy_git fetch origin gh-pages
ditto public/ .deploy_git/
git -C .deploy_git reset --soft origin/gh-pages   # 关键：先把 HEAD 对齐远程
git -C .deploy_git add -A
git -C .deploy_git commit -m "Site updated: ..."
git -C .deploy_git push origin HEAD:gh-pages
```
`reset --soft` 只移动 HEAD、不动工作树，配合 ditto 后的完整内容，等价于「远程内容 ∪ public 内容」，符合只加不删原则，且历史线性可快进。
